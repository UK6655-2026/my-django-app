# Todo List App
2026 8/19-8/21

Djangoで作成したTodoリストアプリです。

## 概要

Todoの追加・編集・削除・完了管理ができます。

ユーザー登録・ログイン機能を実装しており、
ユーザーごとに自分のTodoを管理できます。

## 主な機能

- ユーザー登録
- ログイン・ログアウト
- Todoの追加
- Todoの編集
- Todoの削除
- Todoの完了・未完了
- ユーザーごとのTodo管理

## 使用技術

- Python
- Django
- SQLite
- HTML
- CSS

## 起動方法

```bash
python manage.py runserver
